# Tor, but in Codespaces
###### rather CPU heavy.

This is intended for Codespaces but can probably be used in normal Ubuntu idk

How to install dependencies:
-
Run ```git clone https://github.com/littlekitty2000/cstor.git && cd cstor``` in the terminal to clone this repository.
Now run ```. install.sh``` to install the dependencies.

How to run:
-
Run either ```cstor``` or ```python3 run.py``` while in the repository's folder.
If you chose to not make an alias then run the latter.
Then (once you see a popup in the bottom right of yout screen) click "Ports", find "8080", hover over it, and click the "🌐" symbol to open it in a new page.

How to stop
-
Use either ctrl+c or type ```stop``` and hit enter
